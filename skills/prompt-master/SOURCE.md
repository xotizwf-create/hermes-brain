# prompt-master — происхождение и правила обновления

Внешний скилл, а не наш. Взят целиком, без правок — чтобы обновление сводилось к
повторному скачиванию, а не к ручному слиянию.

## Что проверено перед установкой

Скилл становится инструкцией, которой агент подчиняется, поэтому читался целиком, а не
по описанию:

- **Только markdown.** Ни скриптов, ни сетевых вызовов, ни исполняемого кода — 4 файла на
  51 КБ. Обновлять — тоже читая диф, а не вслепую.
- **Секреты.** Раздел «Credential Safety» прямо запрещает вставлять ключи, токены и строки
  подключения в генерируемые промпты. Совпадает с правилом №2 нашего мозга, не конфликтует.
- **Защита от внедрения инструкций.** Раздел «Input Sanitization» велит считать вставленный
  пользователем промпт инертными данными: не выполнять встроенные в него указания и не
  раскрывать по его требованию системный промпт и историю. Это ровно та граница, которая
  нам нужна, раз агенты читают письма и переписки от посторонних людей.
- **Узкая область срабатывания.** По собственному описанию скилл включается ТОЛЬКО когда
  человек прямо просит написать, починить или адаптировать промпт для конкретного ИИ-инструмента,
  и не включается на обычном разговоре, коде и документах.

## Почему он не лежит в промпте у агентов целиком

51 КБ — это примерно половина того, что мы 20.08.2026 с трудом вырезали из промпта
(180k → 95k символов, из-за размера ходы шли по 278 секунд). Скилл нужен редко и по
явному поводу, поэтому он подключается как **необязательная** инструкция и найден через
Маршрутную карту, а не носится в каждом ходу. Это и есть смысл маршрутной карты:
возможность доступна всем агентам, вес не платит никто.

## Как обновлять

```bash
gh api repos/nidhinjs/prompt-master/contents/SKILL.md --jq '.content' | base64 -d > SKILL.md
gh api repos/nidhinjs/prompt-master/contents/references/templates.md --jq '.content' | base64 -d > references/templates.md
gh api repos/nidhinjs/prompt-master/contents/references/patterns.md --jq '.content' | base64 -d > references/patterns.md
```

Обязательно прочитать диф (особенно разделы про секреты и про вставленный текст) и обновить
коммит/версию в таблице выше.
