# /hh-auto-apply — поиск вакансий на hh.ru из Claude Code

Канон процедуры (правила владельца, режимы, история решений) — [`skills/hh-auto-apply/SKILL.md`](../../../skills/hh-auto-apply/SKILL.md).
Это обёртка для Claude Code: как запускать конвейер с ПК. **Логику и формулировки править в каноне, не здесь.**

**Перед написанием любого сопроводительного читать
[`skills/hh-auto-apply/references/owner-profile-and-cases.md`](../../../skills/hh-auto-apply/references/owner-profile-and-cases.md)** —

## Как запускать

Всё исполняется на сервере **217.198.12.236**; с ПК — через `scripts/run_on_217.py`
(пароль берётся из локального `Albery/.env`, в репозиторий не попадает):

```bash
python scripts/run_on_217.py "<команда на сервере>" [timeout_sec]
```

Пути на сервере:
- скрипт — `/root/.hermes/agent-knowledge/skills/hh-auto-apply/scripts/hh_auto_apply.py`
- интерпретатор — `/usr/local/lib/hermes-agent/venv/bin/python`
- конфиг — `/root/.hermes/state/hh_auto_config.json`, журнал откликов — `hh_applies.json`

| Что нужно | Команда | Требует логин на hh |
|---|---|---|
| Быстрый список вакансий (без LLM, без журнала, ~2–5 мин) | `hh_auto_apply.py --list` | нет |
| Оценка LLM + черновики писем, без откликов и без Telegram | `hh_auto_apply.py --dry-run --max N` | **да** |
| Откликнуться на одобренные владельцем | `hh_auto_apply.py --apply-ids <id,id>` | **да** |

`--list` даёт сырую выдачу после ключевого префильтра — в ней остаётся мусор
(менеджеры, SEO, бухгалтерия). Отбор в человеческий список делает LLM-шаг или сам агент.

## Обязательные проверки

1. **Формат работы.** Правило владельца — **только удалёнка**. hh пропускает гибрид в выдачу,
   поэтому перед тем, как показать вакансию, проверять её страницу:
   `read_vacancy(tab, url)["workFormat"]` должно быть `удалённо` без «на месте работодателя».
2. **Не дублировать отклик.** Источник правды — `hh.ru/applicant/negotiations`, а не только
   `hh_applies.json`: владелец откликается и руками. Повторный отклик бьёт по репутации.
3. **Конфиденциальность.** Названия продуктов и клиентов владельца («Албери» и прочие),
   домены и ссылки на его системы не должны попадать ни в письма, ни в переписку, ни в резюме.
   Опыт описывается обезличенно.
4. **Сессия hh.** Если в выводе `сессия разлогинена` — LLM-шаг и отклики не работают.
   Поднимается только владельцем: `bash /opt/hh-browser-start.sh`, затем вход по noVNC-ссылке.
5. **Память сервера.** На 217 около 1 ГБ RAM. Chrome для hh обычно уже поднят — перед
   запуском смотреть `free -m` и не поднимать второй браузер.

## Cron

Автоматический ежечасный прогон **на паузе с 2026-07-30** по решению владельца
(мешал), вместе с `leadgen-watch`. Возобновление — только по явной просьбе:

```bash
hermes cron resume 4463f177db4e   # hh-auto-apply
hermes cron resume d2a9a1f5abca   # leadgen-watch
```

`hh-forms-watch` (5faacfd11aee) не трогали — он следит за ответами работодателей в ЛС.
Пока пауза стоит, конфиг остаётся в `mode: apply`, но сам по себе конвейер не запускается:
автооткликов без ручного запуска не будет.
