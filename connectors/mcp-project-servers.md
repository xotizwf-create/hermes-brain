# MCP-серверы проекта (Claude Code)

Подключены в `.mcp.json` в корне репозитория, поэтому едут вместе с ним и доступны любой
машине, где открыт этот проект. Это НЕ те же коннекторы, что у Hermes-агента на сервере
(`connectors/mcp-servers.md`) — здесь инструменты для работы в Claude Code.

| Сервер | Зачем | Ключ |
|---|---|---|
| `playwright` | браузер под управлением модели: открыть, кликнуть, заполнить, снять содержимое | не нужен |
| `sequential-thinking` | пошаговое рассуждение с ветвлением и пересмотром шагов | не нужен |
| `context7` | документация библиотек по их версии — меньше выдумок про API | не нужен |
| `firecrawl` | обход и разбор сайтов, извлечение структурированных данных | `FIRECRAWL_API_KEY` |
| `perplexity` | веб-поиск с ответом и ссылками | `PERPLEXITY_API_KEY` |

## Ключи

**В `.mcp.json` ключей нет и быть не может** — там только ссылки вида `${FIRECRAWL_API_KEY}`,
файл лежит в git. Значение задаётся один раз на машине:

```
setx FIRECRAWL_API_KEY "..."
setx PERPLEXITY_API_KEY "..."
```

После `setx` нужно перезапустить Claude Code: переменные читаются при старте процесса.
Пока ключа нет, сервер просто не поднимется — остальные работают.

## Проверка

```
claude mcp list
```

Разовая проверка сервера без Claude Code (ответ должен содержать `serverInfo`):

```
echo {"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"probe","version":"1"}}} | npx -y @modelcontextprotocol/server-sequential-thinking
```

## Грабли

- **Первый запуск медленный:** `npx` тянет пакет в кэш (десятки секунд). Это не зависание.
- **Версии не пришпилены** (`@latest` только у playwright, остальные — текущие мажорные).
  Если сервер вдруг сломался после обновления — пришпилить версию в `.mcp.json`.
- **Playwright MCP и наш воркер Авито — разные вещи.** Воркер (`scripts/avito_worker.py` в
  репозитории Albery) держит ПОСТОЯННЫЙ профиль с живой сессией Авито и работает по
  расписанию; MCP-браузер — разовый инструмент для ручного разбора страниц. Смешивать их
  профили нельзя: параллельный вход в один профиль разлогинивает сессию.
